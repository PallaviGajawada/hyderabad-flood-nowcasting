Build the initial foundation for a project called:

"Hyderabad Urban Flood Nowcasting System"

This is a prototype for predicting urban flood risk and approximate flood depth over a 0–3 hour horizon for Hyderabad, India.

IMPORTANT:
Do NOT build the complete flood simulation yet.
Do NOT fabricate datasets or hydraulic measurements.

For this first step, create only the project foundation.

TECH STACK

Backend:
- Python 3.11+
- FastAPI
- GeoPandas
- Shapely
- Rasterio
- NumPy
- Pandas
- Xarray
- NetworkX
- PyProj

Frontend:
- React
- TypeScript
- Vite
- Leaflet or React-Leaflet

The backend will eventually perform:
1. GIS preprocessing
2. Rainfall-to-runoff estimation
3. Drainage graph construction
4. Hydraulic capacity estimation
5. 2D surface flood simulation
6. 0–3 hour flood forecasting
7. Flood-risk calculation
8. Flood-safe routing

The frontend will eventually provide:
1. Interactive Hyderabad map
2. Flood-depth visualization
3. Rainfall information
4. 0–3 hour forecast timeline
5. Drainage visualization
6. Road-risk visualization
7. Flood-safe route selection

IMPORTANT ARCHITECTURE REQUIREMENT:

Create a rainfall input abstraction/interface.

The system must eventually support:

Historical/scenario rainfall:
IMD rainfall NetCDF

AND future/live rainfall:
Doppler Weather Radar rainfall nowcast

Do not hard-code the model specifically to IMD rainfall.

For now, create the interface and an IMD rainfall adapter placeholder.

DATA LIMITATIONS:

The IMD rainfall dataset is approximately 0.25 degree resolution.
The DEM is approximately 30 m resolution.

Therefore:
- Do not claim true street-level prediction accuracy.
- Do not claim engineering-grade hydraulic prediction.
- Later model outputs must be described as prototype/model estimates.
- Missing hydraulic parameters such as pipe diameter, invert elevation, pipe depth, Manning roughness, manhole locations and hydraulic capacity must NOT be invented at this stage.
