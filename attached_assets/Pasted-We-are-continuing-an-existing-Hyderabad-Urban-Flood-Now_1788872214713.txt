==================================================
B. FLOOD-AWARE SAFE ROUTING
==================================================

Use the existing Hyderabad OSM road graph:

outputs/preprocessed/roads/hyderabad_drive.graphml

and existing road flood-risk data:

outputs/model/flood_depth/road_flood_risk.geojson

Implement a flood-aware routing module.

The routing algorithm should:
1. Load the road graph.
2. Associate flood depth/risk with road edges.
3. Allow a source and destination.
4. Calculate a normal shortest route.
5. Calculate a flood-aware route.
6. Penalize or exclude dangerous flooded roads.
7. Return the safest practical route.

Use configurable thresholds, for example:
- safe: <= 5 cm
- caution: >5 cm and <=15 cm
- dangerous: >15 cm

Do NOT hard-code these values in multiple files.

The routing cost should combine:
- normal travel length/time
- flood-depth penalty
- risk-class penalty

Example conceptual cost:

routing_cost =
    travel_time
    × flood_penalty

where flood_penalty increases as predicted flood depth increases.

Very dangerous roads may be excluded completely using a configurable maximum safe depth.

The route result should contain:
- source
- destination
- route node/edge sequence
- estimated travel distance
- estimated travel time
- maximum predicted flood depth
- average predicted flood depth
- maximum flood risk class
- route safety classification
- whether flooded roads were avoided

Create an API such as:

GET /api/safe-route

Parameters:
source_lat
source_lon
destination_lat
destination_lon
forecast_minutes

Example response:

{
  "status": "ready",
  "source": {...},
  "destination": {...},
  "forecast_minutes": 60,
  "route": [...],
  "distance_m": ...,
  "estimated_time_min": ...,
  "max_flood_depth_cm": ...,
  "mean_flood_depth_cm": ...,
  "max_risk_class": ...,
  "safety": "SAFE",
  "flood_avoided": true
}

Also provide a normal route comparison so the dashboard can show:

Normal route
vs
Flood-safe route
